## What is moe_tune
It is a tool for optimization and tuning, mainly used for performance tuning of different MOE implements.


## How to use

1. for now, just support CK MOE tune
   run

   `
    python moe_tune/moe_tune_runner.py
   `
   
   shapes will be captured in aiter/configs/tuned_fmoe_ck.csv
